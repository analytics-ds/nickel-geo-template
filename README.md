# Maquettes GEO Nickel (datashake)

Deux pages à la DA de nickel.eu, avec les ajouts GEO en pastilles rouges cliquables :

- `compte-pro.html` : page d'offre « Le compte pro des auto-entrepreneurs », 8 pastilles.
- `banque-interdit-bancaire.html` : article du magazine « Quelle banque accepte les interdits bancaires ? », 8 pastilles.

Maquettes de démonstration, non affiliées à Nickel, en `noindex`. Tarifs Nickel repris de nickel.eu, tarifs concurrents relevés sur leurs grilles publiées, à revérifier avant publication.
